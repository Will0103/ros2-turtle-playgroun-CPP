# ROS2 Turtle Playground (C++)

My first ROS2 C++ project.

A turtle catching system developed with ROS2 Jazzy and Modern C++.
The system contains a spawner node and a controller node communicating through custom messages and services.

## Features

- Spawn turtles randomly
- Publish alive turtle list
- Automatically chase target turtles
- Catch turtles using custom ROS2 service
- Launch and YAML parameter support

## ROS2 Concepts

- Publisher / Subscriber
- Service Client / Server
- Custom msg / srv
- Timer
- Launch file
- Parameters
